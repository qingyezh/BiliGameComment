# 2026-09-25 采集台 8787「连接不上」

## 现象

打开 `http://127.0.0.1:8787/` 表现为连不上 / 角标「服务未连接」「连接异常」。

## 根因

1. 采集停止时 `/api/stats` 走全量 `computeStatsStream`，每次读完整 `comments.jsonl`（103496 ≈ 375MB / 57 万条），约 **5–11s**。
2. 前端 `tick()` 每 1.5s `Promise.all` 里带上 `loadStats(false)`，请求堆叠，页面长期停在「连接中…」或转成「连接异常」。
3. 服务本身端口是通的（首页 / health 一直 200），并非端口挂掉。

## 修复

| 位置 | 改动 |
| ---- | ---- |
| `src/server.js` | `/api/stats` 接 `cachedCompute`（指纹=comments.jsonl mtime+size）+ 单飞 `statsInflight` |
| `src/web/app.js` | `loadStats` 移出 1.5s 心跳，改为启动一次 + 30s 低频；force 仍在启停采集后触发 |

## 验证

- force 重扫 ≈5.4s（仅一次）→ 缓存命中 ≈5ms
- `/` `/app.js` `/api/health` `/api/crawl/status` 均 <5ms
